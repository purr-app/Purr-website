Purr’s first macOS beta: a focused, local-first API client for HTTP and GraphQL, built around keeping your requests, responses, and debugging workflow in view.

### What’s included

- HTTP request workflows with Focus Mode and horizontal or vertical split layouts.
- GraphQL schema exploration, autocomplete, multiple operations, and structured variable forms.
- Environments and dynamic variables extracted from previous responses.
- jq and JSONPath response filtering.
- OpenAPI 3 and cURL import.
- Request timing and diagnostics.
- Local-first workspaces and encrypted local response storage.
- Universal macOS app for Apple Silicon and Intel.
- In-app update checks, download progress, and release notes. Restart only when you choose.

### Beta

This is an early beta. Workflows, APIs, and internal formats may change as Purr evolves. Bug reports and feedback are welcome.

Apple code signing and notarization are planned for a later iteration.
