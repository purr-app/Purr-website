This update fixes the first macOS beta based on real installation feedback.

### Fixed

- Jaeger now appears as Purr’s first built-in integration.
- The Purr icon in an empty workspace loads correctly in the installed app.
- Fresh installations no longer ask for a Keychain password when Purr opens. Existing Keychain-backed installations migrate their encryption key once.
- Update checks use the blue Purr action, release notes have a solid application surface, and About Purr no longer appears in the workspace menu.
- The DMG window contains only Purr and the Applications shortcut instead of exposing its volume metadata icon.
- Official macOS downloads are signed with a Developer ID certificate and notarized by Apple for standard Gatekeeper verification.
