### Added

- Import Postman collections and environments into Purr.
- Workspace and request history with execution snapshots, pinning, retention settings, working-copy restoration, and replay using the current context. History preserves responses and uploads, including executions from unsaved or deleted requests.
- Reusable GraphQL schema connections with authentication, introspection headers, cached schemas, and workspace defaults. Choose a connection beside the request URL or create operations from its explorer.
- Per-request redirect limits, timeouts, TLS certificate validation, HTTP versions, and separate controls for sending and storing cookies.
- A workspace activity rail that remains available with the sidebar collapsed. Toggle the sidebar with Cmd+B.

### Improved

- Dynamic variables show dependency chains, extraction errors, cycles, and source execution history. HTTP error responses remain available for extraction.
- Export dynamic request chains as readable curl and jq commands for Bash or zsh.
- Variable references are highlighted; authentication templates hide literal credentials.
- Application menus, queued notifications, native window controls, and settings spacing are refined.

### Fixed

- Variable details crossing workspaces, clipped tooltips, cancellation after request navigation, restored tab selection, error notice alignment, and elapsed-time synchronization during requests.
