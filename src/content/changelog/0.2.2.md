### Improved

- Use template completion and jump to variable definitions in GraphQL endpoints, authentication fields, and header editors.
- Edit shared authentication profiles in place while preserving their order.
- Find workspace deletion at the bottom of General settings.
- Simplified usage statistics settings and moved the beta prompt to a compact banner at the bottom of the window.

### Fixed

- Restored usable name, type, and value columns in multipart form-data bodies.
- Kept workspace and environment menus within the window, wrapped long names, and kept creation options visible.
- Fixed workspace and environment selector positioning, kept Variables beside the environment selector, and prevented sidebar overlap in fullscreen.
- Kept variable previews within the window and limited previews to non-secret static values.
- Prevented conflicting inline variable edits while the definition editor is open.
- Renaming a variable now updates references in saved requests, drafts, schemas, shared settings, and environment overrides while preserving request history.
